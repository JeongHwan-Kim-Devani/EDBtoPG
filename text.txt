================================================================================
  [EPAS to PostgreSQL 이관 가이드]
================================================================================
 
본 스크립트 세트는 EnterpriseDB(EPAS) 환경에서 Community PostgreSQL 환경으로
스키마, 데이터, 파라미터 설정을 이관(Migration) 및 검증하기
위해 제작되었습니다.
 
[사전 준비 사항]
Source DB에서 dump, dumpall 명령어를 이용해 epas directory에 sql file을 넣어둡니다.
 
 
================================================================================
**SQL Export COMMAND**
================================================================================
 
# global - 1번만 export
pg_dumpall -s -h <ip> -d <dbname> -p <port_num> -f 01_global.sql
 
# predata(schema, table, view, function, sequence) - database 별로 export
pg_dump -h <ip> -d <dbname> -p <port_num> --section=pre-data -f 02_predata_<dbname>.sql
 
# data(row data) - database 별로 export
pg_dump -h <ip> -d <dbname> -p <port_num> --section=data -f 03_data_<dbname>.sql
 
# postdata(인덱스, 외래키, 트리거, 제약조건 등 ) - database 별로 export
pg_dump -h <ip> -d <dbname> -p <port_num> --section=post-data -f 04_postdata_<dbname>.sql
 
 
================================================================================
접속정보
================================================================================
 
모든 스크립트(00~07) 상단에 있는 Source(EPAS) 및 Target(PostgreSQL)의 
DB 접속 정보(IP, Port, User, Password)를 실제 환경에 맞게 수정해야 합니다.
 
================================================================================
1. 스크립트 구성 및 역할
================================================================================
 
■ 00_mig.sh (통합 이관 준비 스크립트)
  - 01번부터 05번까지의 스크립트를 순차적으로 자동 실행합니다.
  - 실행 전 스크립트 권한을 체크하고, 오류 발생 시 즉각 작업을 중단하여 
    안전성을 보장합니다.
 
■ 01_parse_global.sh (Global 객체 추출)
  - 데이터베이스 전체에 적용되는 Role(사용자/그룹) 및 Tablespace 정보를 
    추출하여 타겟 DB용 DDL을 생성합니다.
 
■ 02_parse_pre_data.sh (Pre-Data DDL 추출)
  - 데이터 적재 전 필수적인 Database, Schema, Table, Sequence, View 등의 
    구조적 객체(DDL)를 추출합니다.
 
■ 03_parse_data.sh (Data 추출)
  - 실제 테이블의 데이터를 COPY 형태로 추출합니다.
 
■ 04_parse_post_data.sh (Post-Data DDL 추출)
  - 데이터 적재 후 생성해야 성능상 유리한 Index, Constraint(제약조건), 
    Trigger, Rule 등의 객체를 추출합니다.
 
■ 05_parameters.sh (파라미터 및 환경 설정 추출)
  - Source DB(EPAS)의 postgresql.conf, DB 레벨, Role 레벨 파라미터와
    데이터베이스별 설치된 Extension 목록을 리포트 형태로 추출합니다.
    (Target DB 환경 설정 시 참고 자료로 활용됩니다.)
 
■ 06_psql.sh (타겟 DB 이관 실행)
  - 01~04 단계를 통해 `postgres` 디렉터리에 생성된 DDL 및 데이터 파일들을 
    Target DB(PostgreSQL)에 실제로 밀어넣는(Import) 스크립트입니다.
 
■ 07_compare_objects.sh (이관 데이터 비교 검증)
  - 이관 완료 후 Source와 Target 간의 객체 수(Table, Index, Function 등)와 
    테이블별 Row Count를 교차 검증합니다.
  - 데이터 건수가 불일치할 경우, 어떤 데이터가 누락되었는지 최대 100건까지 
    샘플 데이터를 추출하여 리포트로 제공합니다.
 
 
================================================================================
2. 디렉터리 구조 안내
================================================================================
 
작업을 수행하면 현재 경로에 다음과 같은 디렉터리가 생성/활용됩니다.
 
./
├── 00_mig.sh                 (01~04 단계 통합 실행 스크립트)
├── 01~07_*.sh                (단계별 스크립트)
├── postgres/                 (추출된 결과물 및 이관 SQL 파일 저장소)
│    ├── 05_parameters_report.log       (파라미터 환경 분석 리포트)
│    ├── 07_migration_compare_report.log(최종 데이터 비교 검증 리포트)
│    └── removed/                       (EPAS 전용 패키지 등 이관 제외 대상 로그)
 
 
================================================================================
3. 표준 작업 절차 (Execution Flow)
================================================================================
 
[STEP 1] 이관 데이터 및 구조 추출 (Source -> Local)
  $ ./00_mig.sh
  - 위 명령어를 실행하면 01번부터 05번 스크립트가 순차적으로 실행되며, 
    'postgres' 디렉터리에 타겟 적용을 위한 파일들이 준비됩니다.
 
[STEP 2] 파라미터 및 Extension 확인
  - 'postgres/05_parameters_report.log' 파일을 열어 Source DB의 파라미터 
    세팅을 확인합니다.
	사용자가 수동으로 Target DB(PostgreSQL)의 postgresql.conf 등에 필요한 설정을 반영합니다.
 
[STEP 3] 실제 데이터 이관 수행 (Local -> Target)
  $ ./06_psql.sh
  - 준비된 데이터를 Target DB에 실제로 적재합니다.
 
[STEP 4] 이관 검증 (Source vs Target)
  $ ./07_compare_objects.sh
  - 이관이 정상적으로 완료되었는지 객체와 Row Count를 비교합니다.
  - 'postgres/07_compare_report.log' 파일을 확인하여 DIFF(불일치) 
    항목이나 누락 데이터가 없는지 최종 점검합니다.
