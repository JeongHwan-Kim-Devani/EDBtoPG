Migration Workflow Summary

EPAS to PostgreSQL Migration

EPAS에서 PostgreSQL로 이전할 때 수행하는 추출, 변환, 적재, 검증 절차를 업무 리포트 형식으로 정리했습니다. 각 단계는 실행 스크립트와 핵심 산출물을 먼저 확인한 뒤 세부 작업을 표로 훑을 수 있습니다.

참조 문서 EPAStoPG.pdf
단계 수 4단계
세부 항목 32개
01 추출

Source DB에서 DDL, 데이터, 설정, 객체 목록을 확보합니다.

02 변환

EDB 전용 요소를 PostgreSQL 호환 형태로 정제합니다.

03 적재

Target DB에 객체, 데이터, 설정을 순차 반영합니다.

04 검증

객체 수량, 행 수, 시퀀스, 차이점을 비교합니다.

검토 기준: 이 페이지는 EPAStoPG.pdf의 이관 흐름을 빠르게 읽기 위한 요약본입니다. 상세 절차나 명령 실행 기준은 PDF 원문과 각 Shell 스크립트를 최종 기준으로 확인합니다.

01

사전 준비

Source DB에서 이관 대상의 DDL, 데이터, 운영 설정, 비교 기준 목록을 확보합니다.

실행 스크립트 00_source.sh

단계 목적

이관 전 원천 정보를 빠짐없이 수집해 이후 변환과 검증의 기준 데이터를 만듭니다.

핵심 산출물

  • Global, Pre-data, Data, Post-data DDL
  • postgresql.conf 및 pg_hba.conf 기준 정보
  • 객체 수량과 상세 목록 리포트
사전 준비 세부 작업
No 작업 내용
1 Global 객체 추출 Role, Tablespace, Database 등 전역 객체 DDL 추출
2 Database / Role 선택 이관에서 제외할 대상 대화형 입력, Enter 입력 시 전체 대상 처리
3 Pre-data 추출 Schema, Table, View, Function 등 주요 DDL 추출
4 Data 추출 Table 내부에 저장된 실제 Data를 COPY 구문으로 추출
5 Post-data 추출 Index, PK/FK 제약조건, Trigger 등 후처리 객체 추출
6 파라미터 추출 PostgreSQL 호환 소스 DB의 postgresql.conf 환경 설정 추출
7 pg_hba.conf 추출 클라이언트 IP 접속 허용 및 인증 규칙 추출
8 Object 목록 추출 리포트용 객체별 수량 및 상세 목록 자동 생성
02

데이터 변환

추출 결과에서 EDB 전용 옵션과 PostgreSQL 미지원 요소를 정리해 타겟 적용 가능한 산출물을 만듭니다.

실행 스크립트 01_transfer.sh

단계 목적

DDL, COPY 데이터, 환경 설정 스크립트를 PostgreSQL 호환 형식으로 표준화합니다.

핵심 산출물

  • 변환된 Global, Schema, Post-data DDL
  • Target 적용용 conf.sh 및 hba_conf.sh
  • DB Link 매핑과 제외 객체 리포트
데이터 변환 세부 작업
No 작업 내용
1 Global DDL 변환 PROFILE, Resource Group 등 EDB 전용 옵션 제거
2 Schema DDL 변환 EDB 전용 타입 변환 및 Oracle 내장 함수를 PG 문법으로 정제
3 Data 변환 (COPY) 일반 테이블의 COPY 구문을 PG 호환 형식으로 수정
4 Post-Data DDL 변환 미지원 rowid 기반 Index 및 보안 정책(RLS) 제외 처리
5 파라미터 쉘 생성 추출된 postgresql.conf 값을 타겟에 적용할 conf.sh 작성
6 pg_hba.conf 쉘 생성 소스 접속 인증 규칙을 반영하는 hba_conf.sh 작성
7 DB Link 변환 추출된 DB Link를 postgres_fdw / oracle_fdw 매핑으로 변환
8 제외 객체 자동 분류 변환 불가 패키지(DBMS_*) 제외 및 Removed Report 작성
03

데이터 이관

변환된 DDL과 데이터를 Target DB에 적재하고, 설정과 통계 정보를 이관 후 상태에 맞게 갱신합니다.

실행 스크립트 02_import.sh

단계 목적

Target DB에 객체와 데이터를 순차 반영해 서비스 가능한 기본 상태를 구성합니다.

핵심 산출물

  • Target DB 객체와 데이터 적재 결과
  • 동기화된 Sequence 값과 FDW 매핑
  • import_logs 작업 이력
데이터 이관 세부 작업
No 작업 내용
1 Global 객체 이관 Target DB에 Role, Tablespace, Database 순차 생성
2 Pre-Data 이관 Schema, Table, View, Function 등 주요 객체 생성
3 Data 이관 (COPY) 실제 Data 적재 및 Sequence의 현재 값 동기화
4 Post-Data 이관 PK/FK 등의 제약조건과 Index, Trigger 생성
5 파라미터 적용 호환 파라미터(conf.sh)를 타겟 postgresql.conf 하단에 추가
6 pg_hba.conf 적용 기존 규칙 주석 처리 후 Source 환경과 동일한 접근 제어 추가
7 DB Link & 통계 갱신 FDW 연동 매핑 및 Vacuum Analyze를 통한 통계정보 갱신
8 작업 로그 확인 모든 작업 import_logs 디렉터리 저장 및 진행 상태 모니터링
04

이관 결과 검증

Source와 Target의 객체, 데이터, 시퀀스, 확장 모듈 차이를 비교해 정합성을 확인합니다.

실행 스크립트 03_compare_objects.sh

단계 목적

이관 누락, 값 차이, 예외 처리 대상을 분리해 후속 조치가 가능한 검증 결과를 만듭니다.

핵심 산출물

  • 객체 유형별 카운트 비교 결과
  • Table Row Count 및 Sequence 비교 결과
  • MISSING, DIFF, EXCEPTION 상세 리포트
이관 결과 검증 세부 작업
No 작업 내용
1 Object Summary 제외된 수량을 감안하여 유형별 객체 카운트 비교 및 검증
2 Table Row Count 모든 Table의 데이터 행(Row) 개수 정합성 확인
3 Sequence Value Source와 Target의 시퀀스 last_value 값을 비교하여 동기화 점검
4 Partition Object 부모/하위 파티션 구조 확인 및 단위별 데이터 건수 비교
5 Function / Procedure 소스 대비 함수/프로시저 생성 누락 및 미지원 제외 확인
6 View / Index / Trigger 부가 객체들의 누락(MISSING) 항목 정상 이관 여부 검증
7 Extension / DB Link 확장 모듈 버전 정보 및 fdw 서버 매핑 변환 여부 비교
8 차이점 상세 리포팅 MISSING, DIFF, EXCEPTION 등 차이점 사유 상세 로깅 및 요약
