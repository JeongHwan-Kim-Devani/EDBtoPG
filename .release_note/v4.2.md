# Release Note - v4.2 (EPAS 10 Compatibility Hotfix)

Date: 2026-04-20

## Summary
- This release adds backward compatibility for EPAS 10 and below where `pg_proc.prokind` is not available.
- The recommended execution target is now `epas_precheck_v4.2.sh`.

## Included Changes
- Added runtime compatibility branch for `pg_proc.prokind` usage:
  - If `prokind` exists: use `p.prokind`
  - If `prokind` does not exist: use fallback expression based on `proisagg/proiswindow`
- Applied replacement centrally in `read_sql()` so all embedded SQL sections are covered consistently.
- Added RLS policy query compatibility for EPAS/PG 9.x:
  - `permissive` is read through `to_jsonb(pg_policies_row)->>'permissive'` to avoid column-missing errors on 9.5/9.6
  - If `pg_catalog.pg_policies` view does not exist (e.g. 9.4), export creates an empty policy TSV instead of failing
- Re-generated `v4.2` script in a safe path to avoid text corruption during file creation.

## Impact
- Fixes errors like:
  - `ERROR: column p.prokind does not exist`
- Existing report/export flow is unchanged other than compatibility handling.
