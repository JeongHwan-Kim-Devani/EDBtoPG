# Release Note - v4.6 (Policy Catalog Compatibility)

## Summary
- The recommended execution target is now `epas_precheck_v4.6.sh`.
- Policy summary analysis now works safely when `pg_catalog.pg_policy` is unavailable.

## Changes
- Added runtime detection for the `pg_catalog.pg_policy` catalog table.
- Replaced the policy summary CTE body dynamically based on catalog availability.
- Preserved the v4.5 compatibility updates for EPAS 9.4/9.5 and EPAS 11+ environments.

## Verification Target
- Script: `EPAS_PRECHECK/epas_precheck_v4.6.sh`
