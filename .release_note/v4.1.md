# Release Note - v4.1 (Compatibility and Report Metadata Update)

Date: 2026-04-12

## Summary
- This release introduces EPAS version compatibility hardening and report metadata improvements.
- The `v4.1` script is now the recommended execution target.

## Included Changes
- Added version-branch behavior in `epas_precheck_v4.1.sh` for function source extraction:
  - EPAS/PG 14+ uses `pg_get_function_sqlbody(oid)` path
  - EPAS/PG 13 and below uses fallback extraction path
- Added report header metadata display:
  - DB name
  - O/S information
  - EPAS version
- Improved O/S detection logic:
  - Preferred: `pg_read_file('/etc/os-release')` -> `PRETTY_NAME` (when permitted)
  - Fallback: existing `version()` parsing logic
- Fixed details-area typo in report UI text.

## Compatibility Notes
- If DB-side file read permission is unavailable, O/S information automatically falls back to the previous display method.
- Existing output files and report generation flow remain compatible.
